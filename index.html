匣藏 隐私政策

生效日期：2026-09-02 · 联系：iclzh@gmail.com

本政策适用于 Chrome 扩展「匣藏 - 跨平台收藏」。本扩展没有账号系统、云同步或开发者服务器。收藏默认只保存在你这台电脑的浏览器里。

我们收集什么

开发者不收集、不接收、不存储你的任何数据。扩展在你的浏览器本机处理信息。

数据类型存放位置用途
扩展设置（主题、默认收藏集等）本机 chrome.storage.local记住选项
收藏（标题、链接、摘录、图片、标签、备注、收藏集）本机 IndexedDB本机收藏库
加密收藏集的密码派生材料本机存储；解锁状态仅在当前会话保护你加锁的收藏集
可选的 xAI API Key本机 chrome.storage.local仅当你主动使用「Grok 摘要」

不收集姓名、邮箱、电话、精确位置、支付信息、密码（加密收藏集密码只在本机用于解锁，不会上传）、通讯内容、完整浏览历史。

如何使用

仅用于单一用途：把你选择的网页、图片和文本收藏到本机，并用收藏集、标签、流程、快捷键、侧边栏加以整理。不覆盖新标签页，不修改默认搜索引擎，不在搜索结果页注入内容。不用于广告、分析、画像或信贷。目前没有账户登录，也没有跨设备云同步。

是否与第三方共享

默认否。开发者没有后端，不会出售或传输你的收藏。

只有在你主动操作时，才可能向第三方发出请求：

  • 点「Grok 摘要」且你已填写自己的 xAI API Key：会把该条收藏的标题、链接和正文片段发到 api.x.ai，用于生成标题和标签建议。Key 和内容都不会发到开发者。
  • 收藏 YouTube 链接时：可能请求 YouTube oEmbed 以补全标题和封面；在收藏库内嵌播放时，会为嵌入请求补上 YouTube 所需的 Referer。
  • 你自己打开已收藏的链接时：就是普通访问该网站。

权限

  • storage / unlimitedStorage：本机保存设置和收藏（含图片），不上传。
  • activeTab / tabs / scripting：读取你正在收藏的当前页标题、链接、封面，并显示收藏确认框。
  • contextMenus：右键收藏网页、链接、图片、选中文字。
  • sidePanel：在侧边栏打开收藏库。
  • declarativeNetRequestWithHostAccess：仅为扩展内嵌的 YouTube 播放补 Referer，不拦截你的日常上网。
  • 访问所有网址：因为你可以收藏任意网站；内容脚本只用于收藏确认框和快捷键。不会把页面内容发给开发者。

Cookie 与登录态

扩展不提取、导出或上传你在其它网站的 Cookie 或密码。收藏时只读取你允许保存的当前页公开信息（标题、链接、简介、封面、你选中的文字或图片）。

备份与导出

导出 JSON、书签 HTML 或备份到本地文件夹，都由你在本机选择路径。开发者无法看到这些文件。

远程代码

不加载远程脚本。全部代码都在商店安装包内。可选的 Grok 调用只解析 JSON 文本建议，不会执行返回的代码。

Privacy Policy

Effective 2026-09-02 · iclzh@gmail.com

XiaCang (“匣藏”) is a local bookmarking extension. The developer operates no servers, accounts, or cloud sync. It does not override the new tab page, change the default search engine, or inject into search results. Settings stay in chrome.storage.local. Your saved pages, images, and notes stay in IndexedDB on your device. Nothing is uploaded, sold, or used for ads.

Optional: if you paste your own xAI API key and click “Grok summary”, the item’s title, URL, and a text snippet are sent to api.x.ai to suggest a title and tags. YouTube oEmbed/embed requests may run only for YouTube links you saved. No remote code is executed.
